🎬 Movie Search Engine

A simple and responsive **Movie Search Engine** web application built using HTML, CSS, and JavaScript.  
This project allows users to search for movies and view details dynamically.

Features

Search movies by name
Display movie results dynamically
Responsive design (mobile + desktop)
Fast and simple UI
Clean and user-friendly interface

HTML
CSS
JavaScript
Movie API (if used like OMDB or others)
